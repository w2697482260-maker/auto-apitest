# 飞书 Webhook URL 获取详细图解

## 🔍 找不到入口？看这里！

### 📌 关键位置说明

飞书的机器人功能可能在不同版本/语言中显示不同，请按以下方式查找：

---

## 方式一：通过群设置（最常用）

### 步骤 1：打开群聊
找到你想接收测试报告的飞书群

### 步骤 2：点击群名称
- 在群聊界面，点击顶部的 **群名称**
- 或者点击右上角的 **三个点 (···)** / **设置图标 (⚙️)**

### 步骤 3：查找机器人选项
会弹出群设置页面，找以下任一选项：
- `群机器人`
- `Bot`
- `机器人`
- `Bots`
- `Integrations` (英文版)

**找不到？** 往下滚动设置页面，通常在以下位置附近：
- 群公告下方
- 群文件下方
- 群管理选项中

### 步骤 4：添加机器人
- 点击 `添加机器人` / `Add Bot`
- 或者点击 `+` 号

### 步骤 5：选择自定义机器人
在机器人列表中找到：
- `自定义机器人`
- `Custom Bot`
- `Webhook`
- 通常有一个齿轮或设置的图标

### 步骤 6：配置并获取 URL
1. 填写机器人名称（必填）
2. 点击 `添加` / `确定` / `Create`
3. **复制显示的 Webhook URL**

---

## 方式二：通过群设置菜单（电脑版）

```
群聊窗口
  └─ 点击右上角的 「⚙️ 设置」或「···更多」
       └─ 在弹出菜单中找「群机器人」或「Bot」
            └─ 点击「添加机器人」
                 └─ 选择「自定义机器人」
                      └─ 填写信息 → 添加
                           └─ 复制 Webhook URL
```

---

## 方式三：如果群里没有「群机器人」选项

**可能的原因：**

### 1. 权限不足
- 只有 **群主** 和 **管理员** 才能添加机器人
- 解决方法：请群主或管理员帮忙添加

### 2. 企业版功能受限
- 某些企业禁用了自定义机器人功能
- 解决方法：联系企业管理员开通权限

### 3. 版本过旧
- 更新到最新版飞书客户端
- 解决方法：检查更新并升级

## 📱 找到后的操作

### 添加机器人界面

你会看到机器人列表，找到以下任一选项：
- ✅ **自定义机器人** (推荐)
- ✅ **Webhook Bot**
- ✅ **Custom Bot**

**不要选：**
- ❌ 其他第三方机器人（如日历、投票等）

## 🔧 替代方案

如果实在找不到机器人功能，可以使用以下替代方案：

### 方案 A：使用飞书邮箱通知
在配置文件中配置邮件通知（需要额外实现）

### 方案 B：使用企业自建应用
通过飞书开放平台创建应用（更复杂但权限更大）

### 方案 C：临时禁用通知
在 `config/notification_config.yaml` 中设置：
```yaml
feishu:
  enabled: false  # 暂时禁用飞书通知
```

## 📸 快速识别

**正确的位置特征：**
- ✅ 在群设置里
- ✅ 有「机器人」或「Bot」字样
- ✅ 可以看到机器人列表
- ✅ 有「自定义」或「Custom」选项

**错误的位置：**
- ❌ 个人设置（这是群功能）
- ❌ 工作台（这是应用入口）
- ❌ 消息设置（这是通知设置）
